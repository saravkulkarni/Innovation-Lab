What is Machine Learning?

Machine learning is a field within artificial intelligence where algorithms and data are used to learn patterns and make recognise correlations, without being explicitly programmed. Large amounts of data need to be fed to machine learning algorithms before it can be used in a meaninguful way.

Mahine learning is incredibly valuable in scientific research and is widely used. For one thing, scientific instruments such as telescopes collect vast amounts of data that would take large amounts of time and resources to go through. ML algorithms can sort through all this data and find patterns and relationships within the data, and remove anything that is superfluous. These algorithms may pick up on something that might not be noticed by humans, making it a useful tool. 

Recent devleopments in the field, have focused on artificial neural networks. These are designed to mimic neurons in the brain and consist of layers of interconnected nodes. This has led to increasingly sophisticated learning approaches within the field, such as 'deep learning', which can be used on highly complex data. 

As helpful and useful as machine learning is, there are factors and issues that need to be addressed and taken care of. 

Machine learning systems require increasing amounts of energy and these data centres are responsible for a large proportion of global energy consumption. This obviously is a problem and the efficiency of these systems should be improved to begin to ameliorate the situation.
Furthermore, it needs to be clear how the algorithms have come to decisions they have. In fields such as medicine, where the health of patients is involved, medical staff need to understand where the predictions have come from, rather that blindly trusting the outcome. In scientific research, where reproducibility is a key part, every step needs to be clear.
