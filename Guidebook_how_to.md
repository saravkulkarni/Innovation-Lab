## How to make your own guidebook

This guidebook was made using Jupyter Book with both markdown and google colab files. It was then published to the web using GitHub Pages. This page is designed to help you learn how to get started with making your own guidebook (or other kind of website).


Jupyter Book is **not** the same thing as Jupyter Notebook. 
The version of Jupyter Book used for this guidebook is v2.1.6.
Please note that some features are still in beta.



Clicking on the cards below will take you to the relevant pages.


:::{card} 
:link: https://jupyterbook.org/stable/
:header: Jupyter Book User Guide
This is the official documentation for Jupyter Book. It covers a wide range of topics, some of which may not be pertinent to your project. The get started section is the most useful, as it covers in depth the various ways of installing jupyter book and initialising your book.
:::

:::{card}
:link: https://mystmd.org/guide/typography
:header: MyST Markdown
This is the documentation for MyST markdown. MyST is built on CommonMark markdown. Is is used to write content (not executable code, presentation only) and is particularly useful for scientific/mathematical publications. The syntax needed for all the different features is given here, along with examples and directives.
The authoring section is the most relevant part of the website. 
::: 

:::{card}
:link: https://colab.research.google.com/
:header: Google Colab
To write the .ipynb files in this guidebook, google colab was used. Whilst this is not the only option, it is useful to use, especially for educational purposes. Within the google colab file, you can have both text and code cells. Google Colab works best for Python. Although a few other programming languages can be used, it is more complicated and it doesn't work as well. 
:::

Instead of using the default style of the Jupyter Book, a custom CSS file was used for the design of the website. There are many places to learn about CSS and its syntax. However, we found that when it came to working out the class names, that using Google Inspect was incredibly helpful. To do that, right-click over the relevant part of the page and click on the inspect button in the menu. Then look for the class name. Once you know the class name, you can then make targeted changes. 

:::{card}
:link: https://github.com/saravkulkarni/Innovation-Lab/blob/main/custom.css
:header: Tip
If you would like, you are welcome to use the CSS file we made in order to save time. You can then use this as a starting point to then make your own changes. The most immediate change probably being the colour scheme. Clicking on this card will take you to our CSS file on GitHub. 
:::
